# Language validation ledger

No language is verified by this initial scaffold.

For each model + language + locale/dialect combination, record:
- Exact model ID and immutable upstream revision.
- License text and commercial-use review.
- Language tag and dialect.
- STT test set, sample count, WER/CER.
- TTS intelligibility/naturalness evaluation and samples.
- CPU/GPU, VRAM/RAM, latency and real-time factor.
- Runtime egress/privacy verification.
- Pass/fail, date, reviewer and reproducible test command.

Do not claim “all world languages”. Coverage is the union of specifically documented, licensed, installed and tested models. Upstream language listing alone is not proof of AQX quality.
